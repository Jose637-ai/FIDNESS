# FIDNESS

Proyecto académico desarrollado en Java utilizando NetBeans.

## Descripción
FIDNESS es un sistema para consultar ejercicios físicos y crear rutinas personalizadas.

## Funcionalidades
- Inicio de sesión.
- Consulta de categorías de ejercicios.
- Visualización de ejercicios e instrucciones.
- Creación de rutinas personalizadas.
- Consulta de rutinas.
- Exportación de rutinas a archivos TXT.

## Tecnologías
- Java
- Java Swing
- Apache NetBeans
